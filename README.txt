GLASS LAUNCHER - build steps
1. Install Android Studio, then File > Open and choose this folder. Let it sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s)
3. Copy app/build/outputs/apk/debug/app-debug.apk to your phone and install it.
4. Press Home, choose "Glass Launcher" > Always.
5. Swipe down on the home screen once, tap the gear, and use
   "Allow notification access" (and see note about Restricted Settings).
   If it is greyed out: Settings > Apps > Glass Launcher > three dots > Allow restricted settings.
